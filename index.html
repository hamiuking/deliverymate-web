DeliveryMate (Pilot)

Peer‑to‑peer local delivery in New Zealand

Invite-only pilot — Test mode only. Please don’t use for urgent or high‑value deliveries. DeliveryMate is a facilitator only (not a courier, employer, or agent). No disputes or refunds.

How it works

  • Post a request and receive offers from approved drivers.
  • Choose an offer and fund escrow (Stripe test mode during pilot).
  • After delivery: confirm to release immediately, or auto-release after 24 hours.

Request lifecycle (simple)

  1. Create a request — you receive offers from approved drivers.
  2. Accept an offer — this assigns the driver.
  3. Fund escrow — Stripe Checkout (test mode during pilot).
  4. Driver updates status — picked up → delivered.
  5. Escrow enters pending release — after driver marks delivered.
  6. Sender confirms delivery → immediate release.
  7. If sender does nothing → auto‑release after 24 hours.
  8. Payout (pilot) — admin marks paid manually.

Always save your Request ID. DeliveryMate is a facilitator only — not a courier, employer, or agent.

Tester onboarding

  1. Go to Sender to register and create a request (save the Request ID).
  2. Drivers: go to Driver to apply. Admin approval is required before offering.
  3. Sender: load your request to review offers, accept one, and fund escrow.
  4. After delivery: confirm to release escrow immediately, or it auto‑releases after 24 hours.

If you get stuck, send a screenshot + your Request ID.
